# Flipkart Product Prediction App 

This is a Machine Learning web application built using Streamlit.
The app loads a trained ML model and makes predictions based on user input.

## Features

Interactive web app using Streamlit

Loads trained ML model using joblib

Performs predictions in real time

Simple and user-friendly interface

## Technologies Used

Python

Streamlit

Scikit-learn

Pandas

NumPy

Joblib
